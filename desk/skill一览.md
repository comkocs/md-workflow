- `merge-and-deploy` / 并线上服 / 单独装即可用 / 代码改完、要合进公共主线并放到线上时,用这个 skill 按固定顺序一步步做。
- `contract-and-test-infra` / 前后端契约与测试基建 / 单独装即可用 / 后端做完要交给前端、或者对接比预想慢很多时,用这个 skill 先把接口约定和测试底子补齐。
- `closeout-report-drafting` / 收口报告起草 / 单独装即可用 / 这个 skill 帮你在一件活做完时写出一份短、能逐条核对的收口报告。
- `window-handoff-drafting` / 换窗归档起草 / 单独装即可用 / 这个 skill 帮你在旧窗口快写满或收工时,给接手的新窗口写一份交接文件。
- `top-audit-dispatch` / 顶级审计派遣 / 单独装即可用 / 这个 skill 帮你在一单做完并进主线后,派一个独立的审计者按需求逐条核对实际做出来的东西。
- `memory-writing` / 记忆写入与索引 / 单独装即可用 / 这个 skill 帮你把一条下次还会用到的规矩或教训写成一份单独的记忆,并在记忆索引里加一行,让以后新开的窗一眼能找到。
- `verify-agent-claims` / 核子代理与他人报告 / 单独装即可用 / 这个 skill 帮你在子代理或别人报来「没有」「已经做好」「会出错」这类结论时,先核清再采信。
- `shared-checkout-safety` / 共用检出与工作树 / 单独装即可用 / 这个 skill 帮你在多个窗口同时在同一份代码上干活时不互相踩。
- `subagent-delegation` / 子代理分档与回报 / 单独装即可用 / 这个 skill 帮你在把活分给子代理时定好每件活交哪一档模型、怎么切、回报怎么收。
- `engineering-pitfalls-checklist` / 工程坑清单 / 单独装即可用 / 文件开头被悄悄多了看不见的字节、子代理报的内容和远端对不上、部署前检查报版本不一致、命令输出乱码或被吞、测试时过时不过时,用这个 skill 先跑一条对应的检查再下结论。
- `frontend-integration-preflight` / 前端对接预检 / 单独装即可用 / 前端准备接某个后端模块、还没动手对接时,用这个 skill 先核三样东西在不在:接口约定齐不齐,卡住的状态能不能复位回起点,不连真服务器能不能走到要做的界面。
- `zero-window-taskbook-drafting` / 0 号任务书起草 / 需要全套 / 这个 skill 要配合 md-workflow 全套用,它帮你给一个要从头包到尾的模块写好交给 0 号窗的任务书,0 号窗就是只派活、验收、不亲手写代码的总管窗口。
- `memory-index-folding` / 记忆索引折叠 / 需要全套 / 这个 skill 要配合 md-workflow 全套用,它帮你在记忆索引快写满时,把一整节原样挪进单独的分册,原处只留一行入口。
- `ticket-desk-usage` / 工单台用法 / 需要全套 / 这个 skill 要配合 md-workflow 全套用,帮你按自己的角色找到工单台上该做的那几步:接活交活、派活判活、复验收尾、看谁在等你回话。
