# 审计件模板(模块总监派出的顶级审计用)

本文件只管审计件长什么样。派法见 `desk/角色/` 下的顶级审计子代理提示词。

## 首行(格式逐字,N 换成数)

```
幻觉 N / 笔误 N / 漏做 N / 未核 N / 环境限制 N
```

首行就是文件第一行,前面不放标题。环境限制不计入未核。

## 五类各算什么(每一项只进一类)

| 类 | 算进来的 | 例 |
|---|---|---|
| 幻觉 | 收口报告或交付里写了、实物里不存在或与实物相反:哈希、文件、数字、结论 | 报告写已并线,{{远端主支}} 上查不到该提交 |
| 笔误 | 实物在、结论成立,只是字面写错:路径、节名、数字抄错 | 事实段写 12 条,实物 11 条,不影响判据 |
| 漏做 | 需求件判据要求、实物里没有 | 判据要四份,实物三份 |
| 未核 | 本审计能核而没核到的,写明缺什么 | 时间不够,没跑全回归 |
| 环境限制 | 因权限或环境核不了:禁读、无网络、无权限。单列「环境限制,非本单问题」 | 原料目录禁读 |

逐条判据的结论只用五个词:符 / 不符 / 未做 / 未核 / 环境限制。「不符」按性质计幻觉或笔误,「未做」计漏做。每个「符」指得出文件与段落,指不出写「未核」;不编数字、不编结论(闸 8)。
