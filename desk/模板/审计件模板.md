# 审计件模板(完整审计 / 轻审四样)

用法:甲类大型单与改账本 / 协议 / 持久化 / 并线上服脚本的单,派完整审计;其余单轻审四样。审计子代理独立起、不共用施工上下文,只看实物与落盘件,不看收口报告;判据只认任务书 §三。

规矩首条:全员适用,含甲档。不编数字——一切数字来自数据库、接口实测或计算结果,没有就写「无数据」。诚实汇报——测试失败写失败,做不了写阻塞,禁止虚报完成。领域边界——{{产品领域红线}}。

## 完整审计(骨架,整段抄走填空)

```
# <单号> 审计件(<一句话标题>)

符 N / 不符 N / 未核 N / 偏离 N / 漏做 N(首行五类计数,逐类填实数)
关单 = 幻觉(模板里为不符)0、漏做 0、未核已答;笔误只勘误不返工,审计件末尾记『已勘误 N 处』。

## 判据逐条

## 不符项
1. 判据 <N>:差在哪、实量多少。判退的首行标责任:模型责任(执行方做错)/ 出题责任(判据或底数本身错);出题缺陷(前提 / 路径 / 命令 / 边界错)记出题责任,不计员工与模型的账;员工顶回总监底数并给出可复核的现行代码,记加分不记越界。

## 未核与偏离
<未核的写为什么核不了;偏离的写偏了什么、理由;没有写「无」。>
```

## 轻审四样(≤ 1,500 字)

只核四样,每样一段证据,不复跑整轮测试:改动面只在白名单内 / 判据逐条有证据(抽一条复算一个数)/ 完整测试套并线头失败 0 / 收口报告四块齐。

首行写「轻审 · 四样 x/4 过 · 返工 是 / 否」;查出问题按现行处置:窗内小修或总监判返工。
