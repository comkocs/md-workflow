# 收口报告模板(四块定死,全文 ≤ 6,000 字)

落 `{{章程目录}}/<位名>/回执/<单号>_收口报告.md`;丙档不写收口报告,只回一行回执。四块标题逐字照写;数字用命令核、哈希用 git 核,不编数、不写过程流水账。

```
# <单号> 收口报告(<一句话标题>)

## 一、做了什么与并线号
<一段:改了哪些文件;并线提交号(未并写本支提交号);build 与测试结果一行,连基点提交号。>

## 二、判据逐条自核
| # | 判据 | 证据(命令与原样输出 / 文件:行) | 过 / 不过 |
|---|---|---|---|

## 三、未做与偏离
<没做的写为什么、归谁;偏离任务书的逐条写偏了什么、理由;没有写「无」。>

## 四、要拍板人答的
<一题一行:问题、选项与后果、本单先按哪个做;没有写「无」。>

## 收尾三问(≤ 300 字)
1. 通知谁:<要知会谁、在哪知会。>
2. 悬着的单:<还开着或等这单结果的单号与关系;没有写「无」。>
3. 下一步:<收口后自然该做的下一件活;没有写「无」。>
```
