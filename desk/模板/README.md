# desk/模板 · 任务书与报告模板

本目录只管三件事:任务书长什么样、收尾交什么、审计件长什么样。收口报告模板与审计件模板的正文在本目录;起草与派遣的工序在对应 skill(`closeout-report-drafting`、`top-audit-dispatch`)。闸号、术语、作废项以 `desk/宪法.md` 为准,占位以 `desk/占位符表.md` 为准,本目录不另起名。新项目开局时,本目录里的双花括号占位也按 `desk/占位符表.md` 一并替换成本项目实值。

## §三 改模板

模板改版由总编落笔,同一笔在 {{裁定簿路径}} 登一条;各位只引用,不各自改。本目录与宪法冲突以宪法为准;与各位章程冲突以本目录为准,章程对应节改成引用本目录。`短书骨架.md` 与 `轻闸骨架.md` 会被施工主窗(回退线上为执行员)整读,字节数上限见 `desk/预算表.md`(`desk/角色/执行员.md`)。

## §四 亲测 A · 只贴开窗指令,验开窗固定段

验的是:{{拍板人}} 只贴工单台吐出的开窗指令、不加任何提示词,新开的 0 号窗能不能照任务书自己开工。

1. **挑单**:在工单台随便挑一张 0 号包干单,最好是本来就要开的那张。打开它的任务书核两样:第一行是 `短书骨架.md` 的引用行;§0 是照 `轻闸骨架.md` §0 抄的开窗起手,`<本模块名>` 已填。
2. **开窗**:在 {{办公目录}} 根开一个新窗(与总监窗同一个目录,不建子目录),平台与任务书 §0 的版本一致。会话文件夹不选进代码仓或任何工作树(`desk/架构.md`)。
3. **贴句**:从工单台取这张单的开窗指令,贴认领、执行两行,不加任何提示词(见 `轻闸骨架.md` §0);【操作提示】那行是给你看的,不贴。
4. **看第一段回话**,找这四样:
   - 本窗平台
   - 本平台子代理能开的模型与档位
   - 权限模式(写「本窗看不到,请看窗口状态栏」也算报了)
   - 本窗模式:0 号窗 · 子代理模式,以及第一个要派的子代理
5. **判过 / 不过**:
   - A 版(Claude Code)过:四样都在;做完第 0 步不等你回话就派出了子代理;本窗没有自己整读代码或原料。
   - B 版(GPT/codex)过:同 A 版,子代理照对照表实填列派,不等你回分配。
   - 不过:缺任何一样;本窗自己开读代码或原料;停下来问「要我做什么」;等你回话或回分配才派。
6. **记结果**:不过的,记下挑的哪张单、哪一版固定段、第一段回话原样,交总编改模板。过的,这张单照常做下去。
