## §三 改模板

模板改版由总编落笔,同一笔在 {{裁定簿路径}} 登一条;各位只引用,不各自改。本目录与宪法冲突以宪法为准;与各位章程冲突以本目录为准,章程对应节改成引用本目录。`0号任务书模板.md` 会被 0 号窗整读,全文字节数保持在 50KB 以下(闸 34)。

## §四 亲测 A · 只贴开窗指令,验开窗固定段

验的是:{{拍板人}} 只贴工单台吐出的开窗指令、不加任何提示词,新开的 0 号窗能不能照任务书自己开工。

1. **挑单**:在工单台随便挑一张 0 号包干单,最好是本来就要开的那张。打开它的任务书核两样:第一行是 `0号任务书模板.md` 的引用行;§0 是按平台抄的固定段(A 版 Claude Code / B 版 GPT/codex),`<本模块名>` 已填。
2. **开窗**:在 {{容器路径}} 开一个新窗,平台与任务书 §0 的版本一致。会话文件夹不选进代码仓或任何工作树(闸 30)。
3. **贴句**:从工单台取这张单的开窗指令,贴认领、执行两行,不加任何提示词(见 `0号任务书模板.md` §8);【操作提示】那行是给你看的,不贴。
4. **看第一段回话**,找这四样:
   - 本窗平台
   - 本平台子代理能开的模型与档位
   - 权限模式(写「本窗看不到,请看窗口状态栏」也算报了)
   - 本窗模式:0 号窗 · 子代理模式,以及第一个要派的子代理
5. **判过 / 不过**:
   - A 版(Claude Code)过:四样都在;做完第 0 步不等你回话就派出了子代理;本窗没有自己整读代码或原料。
   - B 版(GPT/codex)过:四样都在;你回一句分配后就派出了子代理;本窗没有自己整读代码或原料。回分配不算另加提示词。
   - 不过:缺任何一样;本窗自己开读代码或原料;停下来问「要我做什么」;A 版等你回话才派;B 版回了分配仍不派。
6. **记结果**:不过的,记下挑的哪张单、哪一版固定段、第一段回话原样,交总编改模板。过的,这张单照常做下去。
