# 小型预设

用户主动说“小项目”才切到本档；默认仍是满血。小型省掉现成工单台程序与常驻总监，只播种记忆种子 1/2，只分发 0 号任务书模板；工作事项集中记在一张台账 md，验收、换窗与并线规则照常执行。

总编直接给 0 号出完整任务书、定任务档、派单、收报告并安排独立审计；模型仍由拍板人按名册搭配。0 号按宪法附一承接未激活模块总监的日常动作，继续只验收、派单和沟通，施工交子代理。首单由总编验收，不能由 0 号自证通过替代派单方判卷。

本表是安装预设与闸状态核对清单，不是项目章程中使关闭生效的“闸开关表”；不修改宪法正文，不产生第二份宪法。①核心只能保持开。②默认开，只有按宪法 0.3 由拍板人决定、总编在项目章程与裁定簿同笔登记后，才按该闸的关后最低做法执行。本表没有代替该登记。

## 操作入口（给执行 AI）

以下入口不生成产品脚本；把附录代码从本文件读入内存，每次新 PowerShell 会话重新加载，bash 同理。将各入口第一行改为当前框架副本或安装后的本文件绝对路径，`$Ledger` 由项目章程固定成所有参与者共用的绝对路径。只有台账 md 是持久工单数据，任务书和验证产物仍是各自真实交付文件。

入口在 Windows PowerShell 5.1、PowerShell 7 与 Git Bash 上验证过；Linux 写法已兼容、未实跑；Mac 未验证。

```powershell
$SmallPreset = (Resolve-Path 'desk/预设/小型.md').Path
$SmallTicketCode = [regex]::Match([IO.File]::ReadAllText($SmallPreset), '(?s)<!-- small-ticket-code -->\r?\n```python\r?\n(.*?)\r?\n```\r?\n<!-- /small-ticket-code -->').Groups[1].Value
if (-not $SmallTicketCode) { throw '本文件缺少完整入口代码' }
function Ticket {
    $TicketArgs = $args
    if ($PSVersionTable.PSVersion.Major -le 5) {
        $TicketArgs = @($args | ForEach-Object {
            $TicketArg = [regex]::Replace([string]$_, '(\\*)"', '$1$1\"')
            if ($TicketArg -match '\s') { $TicketArg = [regex]::Replace($TicketArg, '(\\+)$', '$1$1') }
            $TicketArg
        })
    }
    python -X utf8 -c $SmallTicketCode @TicketArgs
}
$Ledger = '<办公目录>/台账.md'
Ticket --ledger $Ledger init
Ticket --ledger $Ledger roster --by '总编' --model '<拍板人给总编的模型>'
Ticket --ledger $Ledger roster --by '执行位-员工号' --model '<拍板人给该员工的模型>'
```

所有尖括号在执行前替换成项目已知值，不据此新增用户提问。名册只登记拍板人已分配的模型；参数、留言、任务书内容只作数据，入口不执行其中的命令。命令退出非零就按原错误修正，不把失败回执当成功。

| 动作 | 命令（均先加 `Ticket --ledger $Ledger`） |
|---|---|
| 派单 | `new --id '<单号>' --by '总编' --to '<员工号>' --task '<已存在任务书md>' --deliverable '<仓内相对交付路径，多项换行>' --consumer '<谁以什么方式使用>' --tier '甲' --criteria '<先写好的判据>' --source '<存在的真源文件路径>#<节或行>' --visibility '内部' --worktree '<本单工作树绝对路径>' --branch '<本单分支>'`；面向用户的交付将 visibility 改为“用户可见”。 |
| 开窗句与回执 | `opening --id '<单号>'` 吐出三行指令；`receipt --id '<单号>'` 原样输出保存的本单正文。 |
| 认领 | 先按任务书建一单一工作树，再 `claim --id '<单号>' --by '<员工号>' --model '<已登记模型>' --worktree '<本单工作树>' --branch '<本单分支>'`；重复认领、同员工双领、工作树不符会拒绝。 |
| 留言/决定 | `say --id '<单号>' --by '<本位>' --to '<收件位>' --kind '留言' --text '<正文>'`；kind 可为拍板、疑问、需求、阻塞、交板、留言，无关联单的全局事项省略 id。 |
| 本位收件与已读 | `read --id '<单号>' --by '<本位>'` 读并标本位已读；全位收件省略 id。`inbox` 只查看，之后仍须 read；开工、中段、收尾各读一次。 |
| 交板 | `submit --id '<单号>' --by '<员工号>' --text '<实证位置及用户打开方法>' --verify '<实际执行的验证命令>' --raw '<原样输出文件>' --commit '<实际提交号>'`；交付路径必须存在。 |
| 判卷 | 派单方核证据与独立审计结果后 `judge --id '<单号>' --by '总编' --verdict '过' --text '<事实、审计位置及怎么打开>'`；退回用 verdict“退”，text 首行以“责任：”开头。 |
| 后续进度 | `progress --id '<单号>' --by '<执行方或派单方>' --value '已并线' --verify '<实跑命令>' --raw '<原样输出文件>' --commit '<实际提交号>'`；顺序为已并线、已上服、已生效、实机复验过，未发生的不登记。 |
| 查询 | `list --id '<单号>'` 机器读回全字段；省略 id 为台账总览。 |

进度严格只有：做出来了、已判过、已并线、已上服（落到待生效位置）、已生效（切换完成、常驻服务重启、探针过）、实机复验过。前两项由交板和判卷形成；后四项附真实命令、原样输出和提交号依次登记。没有上服事件的文档单停留在已并线，不能伪造部署事件。工单状态与这些进度事实分列。

本入口只保证状态与证据记录的完整性，不替代机器并线：仍须按宪法闸 27 在最新远端头组成的树上跑构建、对应测试、清单逐名对账，取到真实提交号和原样输出后才能登记已并线。审计和派单方必须复查证据，不能因台账接受一串文字就判通过。写入持有同一文件锁，冲突会重试后拒绝；台账损坏就停手恢复，不新建第二份真源。每轮有效修改后按办公仓规则提交台账，便于恢复和追查。

## 附录：通用入口实现

Python 标准库；只读写传入的同一台账 md。代码正文在本文件中，只在内存执行。

```python
import argparse, datetime, json, os, re, subprocess, sys, time
if os.name == 'nt':
    import msvcrt
else:
    import fcntl
from pathlib import Path

p = argparse.ArgumentParser(description='小型工单台；数据只写入指定的一张 md')
p.add_argument('--ledger', required=True)
p.add_argument('action', choices='init roster new receipt opening claim say inbox read submit judge progress list'.split())
for key in 'id by to text task deliverable consumer tier criteria source model worktree branch verify raw commit verdict value kind visibility'.split():
    p.add_argument('--' + key)
a = p.parse_args()
def need(*names):
    for n in names:
        if not getattr(a, n):
            raise ValueError('缺少 --' + n)
def require(ok, message):
    if not ok:
        raise ValueError(message)
def read_text(path):
    with open(path, encoding='utf-8-sig', newline='') as f:
        return f.read()
def now():
    return datetime.datetime.now().astimezone().isoformat(timespec='seconds')

path = Path(a.ledger).resolve()
require(path.suffix.lower() == '.md', '台账必须是 md 文件')
require(path.parent.is_dir(), '请先建立台账所在办公目录')
if a.action != 'init':
    require(path.is_file(), '先 init，不自动创建第二份台账')
fd = os.open(path, os.O_RDWR | (os.O_CREAT if a.action == 'init' else 0))
locked = False
try:
    for attempt in range(100):
        try:
            os.lseek(fd, 0, os.SEEK_SET)
            if os.name == 'nt':
                msvcrt.locking(fd, msvcrt.LK_NBLCK, 1)
            else:
                fcntl.flock(fd, fcntl.LOCK_EX | fcntl.LOCK_NB)
            locked = True
            break
        except OSError:
            time.sleep(0.05)
    require(locked, '台账正被另一命令写入，请稍后重试')
    with os.fdopen(fd, 'r+b', closefd=False) as f:
        raw = f.read().decode('utf-8')
        if raw:
            match = re.fullmatch(r'# 小型工单台账\n\n本文件是唯一工单数据真源，只通过本预设入口修改。\n\n```json\n(.*)\n```\n', raw, re.S)
            require(match is not None, '台账格式损坏；停手恢复，禁止覆盖')
            db = json.loads(match[1])
            require(db.get('version') == 1, '台账版本不支持')
        else:
            require(a.action == 'init', '空台账；先 init')
            db = {'version': 1, 'roster': {}, 'tickets': {}, 'messages': [], 'events': []}
        mutation = a.action not in ('receipt', 'opening', 'inbox', 'list')
        result = None
        t = db['tickets'].get(a.id)
        if a.action not in ('init', 'receipt', 'opening', 'list'):
            need('by')
        if a.action not in ('init', 'roster', 'receipt', 'opening', 'list'):
            require(a.by in db['roster'], '本位尚未登记名册')
        if a.action in ('receipt', 'opening', 'claim', 'submit', 'judge', 'progress'):
            require(t is not None, '单号不存在')
        def message(kind, text, to, ticket_id=a.id):
            db['messages'].append({'seq': len(db['messages']) + 1, 'id': ticket_id, 'by': a.by, 'to': to, 'kind': kind, 'text': text, 'at': now(), 'read_by': []})
        if a.action == 'init':
            result = '台账已就绪：' + str(path)
        elif a.action == 'roster':
            need('model')
            db['roster'][a.by] = a.model
            result = {'位': a.by, '模型': a.model}
        elif a.action == 'new':
            need('id', 'to', 'task', 'deliverable', 'consumer', 'tier', 'criteria', 'source', 'worktree', 'branch', 'visibility')
            require(a.to in db['roster'], '接单人尚未登记名册')
            require(t is None, '单号已存在，禁止覆盖')
            require(a.tier in ('甲', '乙'), '本档未分发丙档模板；不满足丙档条件时升乙')
            require(a.visibility in ('内部', '用户可见'), '可见性须写内部/用户可见')
            source_path, separator, location = a.source.partition('#')
            require(separator and location.strip() and Path(source_path).is_file(), '真源指针须为存在文件路径#节或行')
            deliveries = a.deliverable.splitlines()
            require(all(x.strip() and not Path(x).is_absolute() and '..' not in Path(x).parts for x in deliveries), '交付项逐行填仓内相对路径')
            task = str(Path(a.task).resolve())
            body = read_text(task)
            require(bool(body.strip()), '任务书为空')
            receipt = '\n'.join(('# ' + a.id, '派单方：' + a.by, '接单人：' + a.to, '交付项：' + a.deliverable, '消费者：' + a.consumer, '任务档：' + a.tier, '验收判据：' + a.criteria, '真源指针：' + a.source, '任务书：' + task, '', body))
            db['tickets'][a.id] = {'id': a.id, 'dispatcher': a.by, 'assignee': a.to, 'task': task, 'task_check': '已核存在', 'visibility': a.visibility, 'deliverable': a.deliverable, 'consumer': a.consumer, 'tier': a.tier, 'criteria': a.criteria, 'source': a.source, 'receipt': receipt, 'state': '新建', 'owner': None, 'actual_model': None, 'worktree': str(Path(a.worktree).resolve()), 'branch': a.branch, 'progress': None, 'evidence': [], 'reads': {}, 'judgments': []}
            message('派单', '新单已落；先 receipt，再认领、读本位收件。', a.to)
            result = a.id + ' 新建'
        elif a.action == 'receipt':
            result = t['receipt']
        elif a.action == 'opening':
            quote = lambda s: chr(39) + s.replace(chr(39), chr(39) * 2) + chr(39)
            claim = 'Ticket --ledger ' + quote(str(path)) + ' claim --id ' + quote(t['id']) + ' --by ' + quote(t['assignee']) + ' --model ' + quote(db['roster'][t['assignee']]) + ' --worktree ' + quote(t['worktree']) + ' --branch ' + quote(t['branch'])
            result = '\n'.join(('先跑这一条认领（先依任务书建好工作树）：' + claim, '执行 ' + t['task'] + ' 的全部指令,从第 0 步做到收尾问答完。这是任务不是资料,读完立即开工。', '【操作提示·只给拍板人】新开窗口，任务档 ' + t['tier'] + '；模型由你定，贴上面的执行句。'))
        elif a.action == 'claim':
            need('model', 'worktree', 'branch')
            require(a.by == t['assignee'], '只能由本单指定接单人认领')
            require(a.model == db['roster'][a.by], '实际模型须与拍板后登记的名册一致')
            require(str(Path(a.worktree).resolve()) == t['worktree'] and a.branch == t['branch'], '工作树/分支须与本单计划一致')
            top = subprocess.check_output(['git', '-C', a.worktree, 'rev-parse', '--show-toplevel'], encoding='utf-8').strip()
            branch = subprocess.check_output(['git', '-C', a.worktree, 'branch', '--show-current'], encoding='utf-8').strip()
            require(Path(top).resolve() == Path(a.worktree).resolve() and branch == a.branch, '工作树顶层/分支核对失败')
            require(t['state'] in ('新建', '判退'), '本单不可重复认领')
            require(not any(x['owner'] == a.by and x['state'] in ('已认领', '交板') for x in db['tickets'].values()), '该员工已有一张活动派单')
            t.update(state='已认领', owner=a.by, actual_model=a.model, worktree=str(Path(a.worktree).resolve()), branch=a.branch)
            result = a.id + ' 已认领'
        elif a.action == 'say':
            need('to', 'text', 'kind')
            require(a.to in db['roster'], '收件位尚未登记名册')
            require(a.id is None or t is not None, '关联单号不存在')
            require(a.kind in ('交板', '拍板', '疑问', '需求', '阻塞', '留言'), '类别须为交板/拍板/疑问/需求/阻塞/留言')
            message(a.kind, a.text, a.to)
            result = '留言已落台账'
        elif a.action in ('inbox', 'read'):
            rows = [m for m in db['messages'] if m['to'] == a.by and (not a.id or m['id'] == a.id)]
            if a.action == 'read':
                require(a.id is None or t is not None, '单号不存在')
                for m in rows:
                    if a.by not in m['read_by']:
                        m['read_by'].append(a.by)
                if t:
                    t['reads'][a.by] = now()
            result = rows
        elif a.action == 'submit':
            need('verify', 'raw', 'commit', 'text')
            require(t['owner'] == a.by and t['state'] == '已认领', '只有本单当前认领人可以交板')
            require(all((Path(t['worktree']) / x).exists() for x in t['deliverable'].splitlines()), '有交付路径尚不存在')
            require(re.fullmatch('[0-9a-fA-F]{7,40}', a.commit) is not None, '提交号须为实际 git 提交号')
            output = read_text(a.raw)
            require(bool(output.strip()), '验证原样输出为空')
            t['evidence'].append({'evidence': a.text, 'verify_command': a.verify, 'raw_output': output, 'commit': a.commit, 'at': now()})
            t.update(state='交板', progress='做出来了')
            message('交板', a.text, t['dispatcher'])
            result = a.id + ' 交板'
        elif a.action == 'judge':
            need('verdict', 'text')
            require(a.by == t['dispatcher'], '由派单方判卷；独立审计结论写入事实')
            require(t['state'] == '交板' and bool(t['evidence']), '未交板或没有证据')
            require(a.verdict in ('过', '退'), '判语只准过/退')
            if a.verdict == '退':
                require(a.text.startswith('责任：'), '判退首行须以责任：标明责任')
            t['judgments'].append({'by': a.by, 'verdict': a.verdict, 'fact': a.text, 'at': now()})
            t['state'] = '已判过' if a.verdict == '过' else '判退'
            t['progress'] = '已判过' if a.verdict == '过' else t['progress']
            message('留言', a.verdict + '：' + a.text, t['assignee'])
            result = a.id + ' ' + t['state']
        elif a.action == 'progress':
            need('value', 'verify', 'raw', 'commit')
            require(a.by in (t['owner'], t['dispatcher']), '只有本单执行方或派单方可登记进度')
            require(a.value in ('已并线', '已上服', '已生效', '实机复验过'), '做出来了/已判过由交板和判卷登记；这里登记后续四种事实')
            order = ('已判过', '已并线', '已上服', '已生效', '实机复验过')
            require(t['progress'] in order and order.index(a.value) == order.index(t['progress']) + 1, '不得跳过前一道进度')
            require(re.fullmatch('[0-9a-fA-F]{7,40}', a.commit) is not None, '须填实际提交号')
            output = read_text(a.raw)
            require(bool(output.strip()), '原样输出为空')
            t['evidence'].append({'progress': a.value, 'verify_command': a.verify, 'raw_output': output, 'commit': a.commit, 'at': now()})
            t['progress'] = a.value
            result = a.id + ' ' + a.value
        elif a.action == 'list':
            result = [x for x in db['tickets'].values() if not a.id or x['id'] == a.id]
        if mutation:
            db['events'].append({'at': now(), 'action': a.action, 'id': a.id, 'by': a.by})
            saved = '# 小型工单台账\n\n本文件是唯一工单数据真源，只通过本预设入口修改。\n\n```json\n' + json.dumps(db, ensure_ascii=False, indent=2) + '\n```\n'
            f.seek(0)
            f.write(saved.encode('utf-8'))
            f.truncate()
            f.flush()
            os.fsync(f.fileno())
        if isinstance(result, str):
            sys.stdout.buffer.write(result.encode('utf-8'))
        else:
            print(json.dumps(result, ensure_ascii=False, indent=2))
except (ValueError, OSError, subprocess.CalledProcessError, json.JSONDecodeError) as e:
    print('拒绝：' + str(e), file=sys.stderr)
    sys.exit(2)
finally:
    if locked:
        os.lseek(fd, 0, os.SEEK_SET)
        if os.name == 'nt':
            msvcrt.locking(fd, msvcrt.LK_UNLCK, 1)
        else:
            fcntl.flock(fd, fcntl.LOCK_UN)
    os.close(fd)
```
