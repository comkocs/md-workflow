# 模块总监 · 角色模板

> **这是什么**:一位模块总监的章程骨架(现行声明)。模块总监按需激活,一个功能模块一位:把需求件拆成单派给 0 号包干窗,0 号并线后派顶级审计核对。章程只四节,名字与顺序固定:§一 本位管什么 / §二 真源表 / §三 开窗步骤 / §四 规矩只引号;不改名、不增减。正文一律按占位符写。
>
> **什么时候用**:{{拍板人}} 或总编决定激活一个模块、而 {{章程目录}} 下还没有这一位时;或已有旧口径章程(九节)的位要改成现行声明时(见下文「从旧口径改过来」)。
>
> **怎么用**:① 从本段下方那条加粗分隔行的下一行起复制到文末,存成 `{{章程目录}}/<位名>/章程.md`;② 全文 `<位名>` 换成本位名字(其余尖括号如 `<单号>` `<态>` `<日期>` 是运行时字段,留着不换);③ 双花括号占位按 `desk/占位符表.md` 填本项目实值;④【填写:…】逐个写成本位内容,写完删掉括号;⑤ 自检:`grep -n '[{][{]' 章程.md`、`grep -nF "【填写" 章程.md`、`grep -nF "<位名>" 章程.md` 都为空,`grep -c "^## " 章程.md` 等于 4,`wc -c 章程.md` 不超过 6,144;⑥ 同一笔建 `{{章程目录}}/<位名>/接管_现状.md`(按 window-handoff-drafting skill 的现状件模板,只两节)与 `{{章程目录}}/<位名>/资料/归档_<日期>/改动记录.md`(只加头部一行「> 归档件:本位流水只追加到本件末尾」),`git -C {{章程目录}} add -- <逐个路径>` 后提交,把 §三 末尾的激活句交给 {{拍板人}}。逐分钟的做法见 `desk/角色/亲测步骤_填章程.md`。
>
> **体积**:章程按字节量(`wc -c`,与闸 35 的 50KB 同一量法),目标 ≤5,120 字节(≤5KB),硬上限 ≤6,144 字节;超目标时只许压 §四「规矩只引号」的展开,不许为凑数删规矩。
>
> **激活与收窗**:有需求件落到本位时,{{拍板人}} 在 {{办公目录}} 根开窗贴激活句(闸 30);本位需求件全部核符、没有在办单时收窗:整段重写 `接管_现状.md` §一,这一格留着,下次同一激活句再开。
>
> **换窗接管(覆盖式)**:每位一份固定名现状件 `{{章程目录}}/<位名>/接管_现状.md`,只两节:§一 现状(收窗整段重写,首行记本窗起步 token 与上窗基线,含「下窗待办」)/ §二 指针(只列路径与命令)。现状件不带激活句;开窗句固定一行,只在章程 §三。本位流水(改动记录、换窗沿革)只追加到归档件,章程与现状件里不记流水。验收三条:① 起步 token 记进现状件首行,并与上窗比;② 下一窗不回读归档件,回读了在现状件 §一 记缺哪条;③「下窗待办」逐条走完。
>
> **从旧口径改过来**:旧章程与旧接管件(含按日期新建的旧换窗件)整件挪 `{{章程目录}}/<位名>/资料/归档_<日期>/`,只加头部一行(「> 已归档 <日期>:本件只当史料;现行看本位 `章程.md` 与 `接管_现状.md`」(路径写成相对本件的写法);流水接着追加的那份旧章程,头部一行再加半句「本位流水继续追加到本件末尾」);再按本模板重立四节章程、按现状件模板写 `接管_现状.md`;此后流水只追加到归档件。旧条目逐条落到新章程某节、某闸、某 skill 或挪归档,一条不丢。
>
> 宪法_历史附录.md 附二交给角色模板的两条,本模板落在:「二章 2.4.6」按功能模块一条龙包干 → §一 第一句;「三章 15 前半」执行权限边界(能自己跑的不让 {{拍板人}} 跑,首次按类问一次授权)→ §一「绝对不做」末项与 §四 闸 28 那条。

## §一 本位管什么

绝对不做(违反即本位第一条判退依据):写进仓代码或脚本(要量写进 0 号单);跑测试、自并、出方案、替需求件补内容;亲读代码或 >2KB 盘点件(派子代理落 md 只读结论段);任务书写方法、参考实现或自己的理解(见「我理解/应该是」即重写);给 0 号加判据外的验证;巡查找活;改总编那格与公共模板;把能自己跑的命令递给 {{拍板人}} 跑。
