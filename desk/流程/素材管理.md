# 素材管理骨架(可选;首窗判「有美术 / 二进制素材」才装,没有不建本件)

- 两根:在用根(<在用素材目录>)+ 坟墓(<退役素材目录>)。在用根只放还在画面或数据里的素材;坟墓只进不出。
- 在用判定用白名单法:真源 id(<哪个表哪个字段引用它>)、画面位置(<哪屏哪里>)、理由,正向列出;列不进白名单的进坟墓。
- 只移不删:素材从在用根移进坟墓,不物理删除;同一笔在坟墓留还原索引一行(文件名 / 原路径 / 移动日期 / 理由),照它能放回原处。
- 规模上限:<在用根与坟墓各自的上限,由项目填>;到上限先退役再进新的。
- 退役两步:仓外搬运派轻量档、不开执行员;仓内删除一位一单(一名员工一张单,不并单)。
