# 减法审

周期按预设:满血(大型项目)每周一次,周几由 {{拍板人}} 定,默认周六;小型 / 中型预设随每次收口做一次,不定周。首轮 = 需求-026。

## 谁做

- 闸账由总编(未激活时由代行者)每次减法审前更新;满血预设可改由审查员位维护,不新立角色件。
- 减法审本人也由总编或代行者做,按本流程逐条判,判完落件、登簿。

## 输入与对象

- 输入四样:闸账、当日口径、预算表、历史附录。
- 对象四类:闸、当日口径条、模板与章程的节、skill。

## 判法

- 闸看闸账:两周内拦下真问题 0 次且让人等 >0 分钟 → 退役候选。
- 其余对象看近两周有没有被任务书 / 需求件 / 章程引用:`grep -rl` 工单台任务书目录与 {{办公目录}},0 命中 → 退役候选。
- 到期三选一:
  - 退役:整块搬进历史附录「作废」节。
  - 续期:写续期理由与新到期日,最多续一次。
  - 转长期:须连续两次减法审在闸账里记到「拦下真问题 ≥1 次」。

## 输出

- 落一份 `减法审_<日期>.md`,放 {{办公目录}}/总编/ 或代行者目录,四块:退役清单(搬附录)/ 续期清单(带理由与新日期)/ 升级清单(当日口径升到哪)/ 体积复量(预算表每行贴实数)。
- 每次在 {{裁定簿路径}} 登一条。
- 退役项的旧名同笔追加到 desk/作废词表.txt。
