## 这个 skill 是干什么的(人话)

这个 skill 要配合 md-workflow 全套用,它帮你在记忆索引快写满时,把一整节原样挪进单独的分册,原处只留一行入口。索引有长度上限,超出的末尾几行会被悄悄截掉,而被截的往往正是最新写下的规矩。照它折,条目一条不丢,折前折后能逐条对上;不折,新开的窗少读了规矩也不自知。

## 分类

分类:需要 md-workflow 全套

## 用前填这几个名字

本 skill 不需要填名字。

## 什么时候用

- 往记忆索引加了行,量出余量不足 3,000 字符(即超过 21,000 字符)。
- 开窗加载时提示索引有行被截掉,或自己上下文里的索引末行与文件真实末行对不上。
- 折出来的二级入口自己也接近上限。
- 自动提醒按字节喊「索引超限」:先按正确量法复量,真超了才用本 skill 折,别照提醒去删条目。

## 步骤

1. 读本目录 `references/memory-index-folding.md` 照做。
2. 只是要写一条新记忆、或给索引加一行,不用本 skill,改用 memory-writing(记忆写入与索引)。

规则真源是 `desk/memory/规范.md` 的 §4、§5 和 `desk/memory/fold_index.py` 的文件头说明;本目录只排顺序、不抄原文,两处对不上以原件为准。
