# 记忆索引折叠 · 精简步骤

原件是唯一真源:规则在 `desk/memory/规范.md` 的「§4 索引 MEMORY.md」「§5 超限折叠」,脚本是 `desk/memory/fold_index.py`(折法、参数、退出码写在它的文件头说明里,只读那段即可),为什么这样折见 `desk/memory/种子/4_记忆治理.md` 的 4.2~4.4。本文只排顺序,细节一律回原件查。

`<记忆目录>` = 放 MEMORY.md 的记忆目录,位置见 `desk/memory/规范.md` 的「§1 记忆放在哪」。

写一条新记忆、给索引加一行不在本文,见 memory-writing skill。

## 一、判要不要折

1. 量字符数:只用 python 按 UTF-8 读取后取长度;`wc -c`、`wc -m` 和按字节喊超限的自动提醒都不作数。细节见 `desk/memory/规范.md` 的「§4 索引 MEMORY.md」量法。
2. 比末行:自己上下文里看到的索引末行,与 `tail -1 <记忆目录>/MEMORY.md` 逐字比,不一致就是已被截。细节同上「判有没有被截断」。
3. 超过 21,000 字符(余量不足 3,000)、或开窗提示有行被截、或二级入口自己也快满,就折;都不是就不动。细节见 `desk/memory/规范.md` 的「§5 超限折叠」何时折。

## 二、选节

4. 挑内容稳定、不必每窗都看的节,记下 `## ` 后面的节名原文,再起一个英文 slug;每窗必读的节(接管指针那一节)不折。细节见 `desk/memory/规范.md` 的「§5 超限折叠」折哪节。
5. 赶时间可以不挑,改用 `--auto`,脚本从最大的节起逐节折到不超上限。

## 三、折

6. 备份:先把 `<记忆目录>/MEMORY.md` 复制到记忆目录外,文件名带当天日期。
7. 演练(只算、只核、只报告,不写文件):
   `python desk/memory/fold_index.py <记忆目录>/MEMORY.md --section "<节名>" --slug <英文-slug> --dry-run`
8. 演练报告里守恒式两边相等、退出码 0,再去掉 `--dry-run` 正式折;`--section` 与 `--slug` 可重复,按先后一一配对。不挑节时换成 `--auto`(上限默认 24000,要改用 `--limit`)。
9. 退出码 0 成功;1 核对失败或输入不合规,此时一个文件都没写,按打印的原因改了再跑;2 参数写错。带 BOM 或 CRLF 的索引先规范化再折;写出的文件仍为 UTF-8 无 BOM、LF。
10. 其余参数(`--date`、`--selftest`、`--out`)和脚本具体怎么搬、怎么核,见 `desk/memory/fold_index.py` 文件头说明与 `desk/memory/规范.md` 的「§5 超限折叠」脚本做什么。

## 四、折后自核

11. 看报告最后一行 `末行: …`,去掉前缀后与 `tail -1 <记忆目录>/MEMORY.md` 逐字相同。
12. 按第 1 步的量法再量一次,必须不超上限。
13. 备份件、折后索引、二级入口各数一次顶格 `- ` 开头的行,代入守恒式。细节见 `desk/memory/规范.md` 的「§5 超限折叠」条目守恒、折后自核三步。
14. 想便于召回,只改入口行的钩子文字补几个关键词,条目数不变。

## 五、二级入口也满了

15. 先给二级入口加几个 `## ` 小节标题(只加标题行、不动条目),再用同一脚本对它折出三级入口。
16. 最多到三级;三级再超就删过期条目或拆主题,不再往下折。细节见 `desk/memory/规范.md` 的「§5 超限折叠」二级、三级入口。

## 谁来折

索引归总编管,超限由总编折;别的位只加、删自己那一行,不替别位删条目。细节见 `desk/memory/规范.md` 的「§4 索引 MEMORY.md」谁维护。
