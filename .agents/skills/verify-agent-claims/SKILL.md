## 这个 skill 是干什么的(人话)

这个 skill 帮你在子代理或别人报来「没有」「已经做好」「会出错」这类结论时,先核清再采信。它教你问清对方是在哪个版本上看的、拿什么算出来的,再换一条路自己复核一遍。不用它,看错版本、搜漏地方、只读了注释得出的结论会被当成事实写进后续文件,下游跟着返工。

## 分类

分类:单独装即可用

## 用前填这几个名字

- {{远端主支}}:远端主干分支的完整引用名,所有复核都对它量;例:origin/main
- {{代码托管远端}}:主代码仓的 git 远端名,复核前先从它取最新;例:origin

## 什么时候用

- 回报说某东西「不存在」「没人用」「改了不影响别处」「没并入」。
- 回报说「已做」「已写入」「已提交」「某测试已经核过」。
- 回报说「会崩」「会红」「预期全绿」,但没附真跑的原样输出。
- 回报推翻了先前的结论,或和别人报的数对不上。
- 一道检查给了「是」「已处理」「是最新」的肯定答复,你准备据此放行。
- 要把别人的结论抄进任务书、章程或交接件之前。

## 步骤

1. 对照「用前填这几个名字」一节,把正文里的对应说法换成你们的实值。
2. 读本目录 `references/verify-agent-claims.md` 照做;那份就是完整做法,和别处说法对不上时以本 skill 为准。
