## 这个 skill 是干什么的(人话)

这个 skill 要配合 md-workflow 全套用,帮你按自己的角色找到工单台上该做的那几步:接活交活、派活判活、复验收尾、看谁在等你回话。每一步只给一两行要点,细节再回原说明按节查,不用把整份长说明读完。不用它,常见的坑是把本机旧数据当成服务器数据、为了字没写对就停下整扇窗、或者漏看了等你答复的单。

## 分类

分类:需要 md-workflow 全套

## 用前填这几个名字

- `{{工单台命令}}`:工单台命令行入口,所有子命令接在它后面,在仓根跑;入口分只读写本机台的和连服务器的两种,前者永远只连本机、不跟随通道配置,要连服务器的窗填后者;例:只连本机台填 `python -X utf8 core/t.py`,跟随通道配置、可连服务器的填 `python -X utf8 core/tools/tickets/ticket.py`。

## 什么时候用

- 刚开一扇工位窗,要接通工单台、核通道、看有没有等你答的单时。
- 员工认领一张单、中途卡住、要交板时。
- 总监建派单、改单、作废、解卡、导出任务书时。
- 判卷、判退、判过了不并线、判过后退回重做、收到停用线通知时。
- 复检复验、实机复验、改当前值面、0 号窗的免判卷单自并收口时。
- 要提问、答复、转交、在对话线上留言时。

## 步骤

1. 任何窗开工先接通、核通道;命令被拦下先看退出码:读本目录 `references/connect-and-errors.md` 照做。
2. 员工第 0 步、认领、卡住、交板:读本目录 `references/worker-claim-submit.md` 照做。
3. 看待答、提问答复、转交、对话线留言:读本目录 `references/threads-and-inbox.md` 照做。
4. 总监建派单、改单、作废、解卡、导出任务书:读本目录 `references/director-dispatch.md` 照做。
5. 判卷、判退责任、不并线结案、判过后退回重做、停用线通知:读本目录 `references/judge-and-rework.md` 照做。
6. 复检复验、实机复验、当前值面、终态退役、0 号免判卷单自并收口:读本目录 `references/review-and-wrapup.md` 照做。

原件 `core/tools/tickets/README.md` 很长,references 点到哪一节就只读那一节,别整读;原件是唯一真源,两边对不上以原件与 `{{工单台命令}} <子命令> -h` 为准。维护者向内容(数据层与配置、图片压缩、库迁移、测试、协议降级白名单、上服闸、网页刷新)本 skill 不收,要改工单台本身时去原件对应节读。
