## 这个 skill 是干什么的(人话)

这个 skill 帮你在公开仓库前查出不该带出去的秘密、身份和素材。它把能跑的检查与必须人工确认的授权分开，防止只改了当前文件，却把历史里的敏感内容一起公开。

## 分类

分类:单独装即可用

## 用前填这几个名字

- 待发布仓与公开范围：先定公开现树还是连同旧历史公开，审查在独立副本中做；不得直接对生产仓执行历史重写或推送。
- `IDENTITIES`：仓外的账号、用户名名单文件；`REAL_NAMES`：仓外的真实人名名单文件；`QUOTES`：仓外的原话片段名单文件。每行一项，不留空行，设置为本机文件路径但不提交；没有名单就记录该项未核，不能写成零命中。
- 授权证据位置：字体许可、生成服务条款、外包归属协议、第三方资产来源与授权清单；证据缺失不能算通过。
- 拍板人：决定公开原话、历史处理与素材去留的人。若使用代理，只写顶级、困难、日常、轻量四档词，不写具体模型名。

## 什么时候用

- 私有代码仓首次公开、同步公开仓，或决定是否保留旧历史之前。
- 从内部工作流提炼可公开的模板、规则、工具和示例时。
- 更换公开范围、补进素材或合并旧分支，需要重新核证据时。

## 步骤

### 1. 固定检查对象

在已备份的独立仓库副本根目录运行下列命令，先用 `git rev-parse HEAD` 和 `git status --short` 记录提交与改动。备齐全部待公开分支和标签，不能只凭浅克隆或当前分支宣布历史安全；用 `git rev-parse --is-shallow-repository` 和 `git for-each-ref --format='%(refname)'` 核范围。安装 gitleaks 后确认 `gitleaks version` 可运行，缺工具就报未核，不以没有输出代替执行成功。

下面的文件名扫描只提供候选，不替代人工判定。`git grep` 无命中退出码为 1；扫描器告警、运行失败与工具缺失要分别记录。日志只存脱敏摘要、命中件数和处置证据，不回贴密钥、地址或个人名单。

### 2. 密钥与口令

| 检查项 | 可跑命令 | 要做 |
|---|---|---|
| 入仓环境配置 | `git ls-files -- '.env' '.env.*' ':(glob)**/.env' ':(glob)**/.env.*' ':(glob)**/*.env'` | 真值移出仓并轮换，示例件只留占位。 |
| 口令字样与完整历史 | `gitleaks git . --log-opts="--all" --redact --exit-code 1` | 扫全部已备齐的历史引用，不只现树；发现的值先撤销或轮换，再按既定方案清理历史。 |
| 私钥文件 | `git grep -IlE -e '-----BEGIN ([A-Z0-9]+ )*PRIVATE KEY-----'` | 检查命中内容与密钥文件，移出仓并撤销对应凭据；不能只改后缀。 |
| 仓外凭据 | `git config --name-only --get-regexp '^credential\.'` | 此命令只列凭据配置键作为盘点入口；另核宿主和服务端凭据台账，开源前一并轮换，不因仓内零命中跳过。 |

### 3. 地址与部署信息

| 检查项 | 可跑命令 | 要做 |
|---|---|---|
| 数字地址候选 | `git grep -IlE '([0-9]{1,3}\.){3}[0-9]{1,3}'` | 人工排除回环、通配、掩码、版本号误报，公网地址换占位，内网地址整类删除。 |
| 部署脚本服务器信息 | `git grep -IlEi -e 'host[[:space:]]*[:=]' -e 'server[[:space:]]*[:=]' -e 'endpoint[[:space:]]*[:=]' -e 'port[[:space:]]*[:=]' -- '*.sh' '*.ps1' '*.py' '*.yaml' '*.yml' '*.json'` | 核地址、账号和连接参数，改读环境变量；脚本外的部署配置同样核。 |
| 现树明文配置 | `gitleaks dir . --redact --exit-code 1` | 覆盖当前文件及未跟踪配置候选；先去掉现树真值，历史另按已定方案处理，不能用现树安全代替历史安全。 |

### 4. 路径与身份

| 检查项 | 可跑命令 | 要做 |
|---|---|---|
| 本机绝对路径 | `git grep -IlE -e '(^|[^[:alpha:]])[[:alpha:]]:[/\\]' -e '/(Users|home)/[^/[:space:]]+'` | 换成相对路径或工作根占位，不暴露系统用户名与目录。 |
| 提交者身份 | `git log --all --format='%aN <%aE> / %cN <%cE>'` | 在本机审身份；经批准的新历史首发不带旧身份，保留或重写历史时配置 mailmap 并核实际发布历史，展示映射不等于已抹原始对象。 |
| 账号名字样 | `git grep -IlF -f "$IDENTITIES"` | 按已确认名单统一替换；名单文件不入仓。 |
| 个人邮箱字样 | `git grep -IlE '[[:alnum:]._%+-]+@[[:alnum:].-]+\.[[:alpha:]]{2,}'` | 去掉个人邮箱，区分获准公开的公共联系地址。 |
| 中文真实人名 | `git grep -IlF -f "$REAL_NAMES"` | 按拍板人名单替换，发布前再人工抽读，名单扫描不能保证发现所有人名。 |
| 设计者原话 | `git grep -IlF -f "$QUOTES"` | 默认不公开；由拍板人逐项确认可否发布，未知片段另作人工抽读。 |

### 5. 版权与素材

| 检查项 | 可跑命令 | 要做 |
|---|---|---|
| 商用游戏及第三方资产 | `git ls-files -- '*.png' '*.jpg' '*.jpeg' '*.webp' '*.glb' '*.gltf' '*.fbx' '*.wav' '*.mp3'` | 核每件来源与授权，禁止未经授权的商用资产；历史中的资产另按历史方案处理。 |
| 入仓依赖目录 | `git ls-files -- ':(glob)**/node_modules/**'` | 删除入仓依赖包，保留依赖声明与锁文件，不把第三方包原目录带入公开仓。 |
| 字体 | `git ls-files -- '*.ttf' '*.otf' '*.woff' '*.woff2'` | 逐件确认再分发许可，并随包附许可文本。 |
| 生成素材 | `git ls-files -- '*.png' '*.jpg' '*.jpeg' '*.webp' '*.svg'` | 对清单逐件标注是否生成，逐家核生成服务条款能否按目标开源许可再发布，核不清就不公开。 |
| 外包美术 | `git ls-files -- '*.psd' '*.blend' '*.fbx' '*.glb' '*.gltf' '*.png'` | 对清单逐件核外包来源，公开前取得版权归属和再分发权的书面约定。 |
| 他家游戏截图与画风参考 | `git ls-files -- '*.png' '*.jpg' '*.jpeg' '*.webp' '*.gif'` | 人工辨认参考图；可内部参考不等于能公开，未获再分发授权的截图保持不入仓。 |

### 6. 体积

运行 `git count-objects -vH` 核对象与打包体积，再用 `git rev-list --objects --all` 盘点历史对象；当前目录小不代表历史小。定位大素材后决定改用大文件存储或外部下载，并核许可与下载入口。新历史首发、重写历史或保留历史由拍板人定，不因体积检查自行删历史；最终对实际发布副本重核。

### 7. 三类仓

按待发布内容给仓内材料分三类：可直接公开的规则、模板、角色定义与流程建议，仍须过前述脱敏；改写后公开的决策与经验记录，只留可公开的编号、日期、题目、起因和改动摘要；不可原样公开的工单数据库、会话记录与共享记忆，默认排除。三类不是按仓名免检，混合仓逐件归类。聚合入口删去地址，接入方式只保留「经本机聚合口」，不得带出通道凭据。

### 8. 对实际发布树收口

逐项记录命中、处置、证据与未核项；命令零命中不等于版权授权通过。若旧值曾入仓，轮换与历史处理分别留证。重新核实际准备公开的树和历史引用，未核项与例外必须由拍板人明确决定；本 skill 只做预检，不授权推送、重写历史或公开原话。
