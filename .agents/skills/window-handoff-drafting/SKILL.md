## 这个 skill 是干什么的(人话)

这个 skill 帮你在旧窗口快写满或收工时,给接手的新窗口写一份交接文件。总编、总监各一份固定名的现状件,收窗时把现状那段整段重写,只写此刻的现状和下一窗待办;旧东西挪进归档目录,流水只往那里追加;开新窗贴的那句话只写在章程里,指向章程。不用它,新窗口常读不完长篇历史,或读到过期的内容被带偏。

## 分类

分类:单独装即可用

## 用前填这几个名字

- {{章程目录}}:各位章程所在的根目录,即 `references/` 里模板与规范写的「<办公目录>」,现状件、归档件与 0 号交接件都落在它下面;例:`_office`
- {{拍板人}}:唯一有最终裁定权的人的称谓,即 `references/` 里模板与规范写的「设计者」;例:设计者
- {{归档字符上限}}:总编、总监的现状件各自最多多少字符;例:24000
- {{交接件字数上限}}:0 号交接件最多多少字(按字符计);例:6000

## 什么时候用

- 旧窗上下文快满,或本窗收工,要换一扇新窗接着干。
- 总编、总监收窗,要整段重写本位现状件 §一。
- 旧口径的位(章程连流水、按日期或版号另存的接管件)要改成「章程 + 现状件 + 归档件」。
- 一张 0 号单做不完,要交给下一棒。
- {{拍板人}}要开一扇只读分身窗,需要指向章程的分身开窗句。

## 步骤

读本目录 `references/handoff-steps.md` 照做;三份模板是本目录 `references/chief-editor-archive-template.md`(总编现状件)、`references/director-takeover-template.md`(总监现状件)、`references/zero-window-handoff-template.md`(0 号交接件),开场命令、开窗句、归档件和各份放哪、怎么更新在本目录 `references/window-handoff-spec.md`。

1. 按接手角色定写哪份;单已做完就改写收口报告。
2. 定谁起草:交子代理做,平台没有子代理就自己做;按角色定谁核。
3. 跑公共开场命令取实值。
4. 抄 `references/` 下对应模板填空。
5. 只写现状与下一步。
6. 按该份的更新方式落盘:现状件整段重写,流水只追加到归档件。
7. 开窗句只指章程,现状件不带。
8. 按字符量篇幅。
9. 用命令核哈希、数字、文件名。
10. 过验收三条:起步 token 与上窗比、不回读归档件、下窗待办逐条走完。
11. 0 号窗收窗清记忆。
