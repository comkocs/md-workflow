# 换窗归档起草 · 精简步骤

换窗规矩在本目录 `references/window-handoff-spec.md`(下文「换窗接管规范 7.x」指它的 7.x 小节),三份模板也在本目录:`references/chief-editor-archive-template.md`、`references/director-takeover-template.md`、`references/zero-window-handoff-template.md`。本文件只列三种接手角色的差别与步骤,细节回这四份读,不在这里抄;两边对不上时以这四份为准。

## 三种接手角色差在哪

| 接手角色 | 写哪份 · 放哪 | 怎么更新 | 起草 / 核 | 篇幅上限 | 模板 |
|---|---|---|---|---|---|
| 总编 | 总编换窗归档 · `{{章程目录}}/总编/换窗归档_第<N>版.md` | 版号滚动:写新一版,旧版整份移入同目录 `归档旧版/` | 总编本窗(上下文已很大时交子代理)/ 总编本窗 | {{归档字符上限}} 字符 | `references/chief-editor-archive-template.md` |
| 总监 | 总监接管件 · `{{章程目录}}/<位名>/接管件.md`(固定名) | 整份重写:先把旧版整份移入同目录 `归档旧版/`(文件名带时间) | 总监本窗(同上)/ 总监本窗 | {{归档字符上限}} 字符 | `references/director-takeover-template.md` |
| 0 号窗 | 0 号交接件 · `{{章程目录}}/<位名>/任务书/<单号>_交接件.md` | 一单一份,做不完才写;同一单再交接就整份重写 | 子代理 / 0 号本体只核 | {{交接件字数上限}} 字 | `references/zero-window-handoff-template.md` |

各份独有的节(怎么填见对应模板的填法行):
- 总编换窗归档:§五 裁定速查;末节「开窗句」两式(全权接管 / 只读分身)。
- 总监接管件:§二 在跑单表;§五 边界与派单(含收窗三步);末节「激活句」两式。
- 0 号交接件:★ 覆盖性判定({{拍板人}}本单当面改过的口径逐字引用);§〇 接棒起手;§一 已完成表;末尾「核对记录」;模板不设开窗句节,也没有只读分身读法,开窗只用换窗接管规范 7.5 的全权接管句(从 §〇 第 1 步起)。

放哪、命名、怎么更新见换窗接管规范 7.3;谁起草谁核见换窗接管规范 7.2;篇幅与三份共同铁律见换窗接管规范 7.1。

## 步骤

1. **定写哪份**:按上表对号;0 号单已做完就不写交接件,改写收口报告(用 `closeout-report-drafting` skill;没装它就照换窗接管规范 7.7 的四块写,`zero-window-handoff-template.md` 文末附里也有这四块的填空式)。细节见换窗接管规范 7.1、7.3。
2. **定谁起草、谁核**:按上表;要交子代理的,交子代理做,平台没有子代理就自己做。收口要读的大件只让起草者读,本体只收结论。细节见换窗接管规范 7.2。
3. **取实值**:跑公共开场命令(核仓路径、取远端、看基点、量记忆索引、取时间戳),命令原样在换窗接管规范 7.4 的代码块里,逐条跑;件里的哈希与时间一律用这里的输出,不凭印象写。
4. **抄模板填空**:尖括号换实值,以「> 」开头的填法行写完删掉;模板里查收待办那一步写本项目实际查收待办的命令或目录。细节见各模板抬头与各节填法行。
5. **只写现状与下一步**:不复述历史、不写推导过程、不逐句转录对话、不写本窗流水账;「下一步」第 1 条就是接手后的第一件事。细节见换窗接管规范 7.1 的共同铁律与各模板 §三。
6. **按更新方式落盘**:归档写新版并把旧版整份移走;接管件先移旧版再整份重写;交接件同单整份重写;哪份都不往件里追加历史段。细节见换窗接管规范 7.3。
7. **写开窗句**:全权接管句的起止点要可核(第几节、第几步),「这是任务不是资料」那半句逐字保留,本次专属要求加在句尾;总编、总监另附只读分身句,不另存分身版文件。细节见换窗接管规范 7.5 与各模板末节。
8. **量篇幅**:按字符量,不按字节量,不超上表上限。量法:用 `zero-window-handoff-template.md`「核对记录」篇幅那一行的 python 命令,路径换成要量的那份,三份通用;`wc` 一类命令碰上中文常数成字节,不作数。
9. **核**:哈希用 git 核、数字用命令核、文件名用列目录核;0 号交接件把命令与输出原样贴进「核对记录」,不写「已核」了事。细节见换窗接管规范 7.2 与 `zero-window-handoff-template.md`「核对记录」。
10. **改接管指针**:总编、总监换版或重写后,只改记忆里本位接管指针那一行(指向新版,或改成新时间戳),不在指针文件里追加段。细节见换窗接管规范 7.3「记忆里的接管指针」与两份模板里的收窗三步。
11. **0 号窗收窗**:删掉本窗写进记忆目录的文件和对应索引行,同一步做;交接件要自包含,接棒者不继承任何记忆也能开工。细节见换窗接管规范 7.6。
