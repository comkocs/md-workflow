## 这个 skill 是干什么的(人话)

这个 skill 帮你在闸账、当日口径和预算表攒满要清的时候,按减法审流程逐条判谁退役、谁续期、谁升级。它把「规矩只加不减」变成「到期能退、续期有数、体积复量」。最后产出一份六块的减法审报告并登裁定簿。

## 分类

分类:单独装即可用

依据:步骤与两份模板在本目录内自包含;办公目录、预算表、历史附录与裁定簿由使用方提供,不依赖产品脚本或外置流程文件。

## 什么时候用

- 到了预设的减法审周期:满血(大型项目)每周一次,周几由 {{拍板人}} 定,默认周六;小型 / 中型预设随每次收口做一次,不定周。
- 有闸或当日口径条到期,要做退役 / 续期 / 转长期三选一时。

## 怎么做(步骤)

1. 先更闸账:由总编(未激活时由代行者)逐闸更新两周数据;满血预设可改由审查员位维护,不新立角色件。模板见 references/闸账.md。
2. 收输入五样:闸账、当日口径、预算表、历史附录、减法提议(有才收)。当日口径模板见 references/当日口径.md。
3. 逐对象判:
   - 在岗窗只列不改;不以体积为目标。
   - 闸:看闸账,两周内拦下真问题 0 次且让人等 >0 分钟 → 退役候选。
   - 共用记忆(有才查,判留 / 改指针 / 移出)。
   - 其余(当日口径条、模板与章程的节、skill):看近两周有没有被任务书 / 需求件 / 章程引用,用 grep -rl 查任务书目录与 {{办公目录}},0 命中 → 退役候选。
   - 辅助定位示例(自拟):`git log --since=14.days --format= --name-only -- desk .agents | sort | uniq -c | sort -rn | head`。
   - 审批句检索示例(自拟):`git grep -n -E "须经|批准后|审批" -- desk .agents`。
4. 到期三选一:
   - 退役:整块搬进历史附录「作废」节。
   - 续期:写续期理由与新到期日,最多续一次。
   - 转长期:须连续两次减法审在闸账里记到「拦下真问题 ≥1 次」。
5. 升级:当日口径条活过 7 天仍在用 → 减法审时升进模板 / 章程 / 宪法。升进宪法的那条须写全四写:拦什么 / 回口 / 拆除条件(用数字说)/ 到期日;到期日默认 = 立闸日 + 7 天;写不出到期日的只留在当日口径孵化区,不得进宪法。
6. 落一份 `减法审_<日期>.md`,放 {{办公目录}}/总编/ 或代行者目录,六块:退役清单(搬附录)/ 续期清单(带理由与新日期)/ 升级清单(当日口径升到哪)/ 体积复量(预算表每行贴实数)/ 位提回写 / 做成工具。
   - 位提回写:减法提议逐条标「位提」,位提优先;另起一行引原行回写「采 / 不采 + 理由」,不采也回。
   - 做成工具:可执行约束优先工具化,正文只留入口指针。
7. 每次在 {{裁定簿路径}} 登一条。
