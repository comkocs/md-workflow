# 模型对照表

两档厂商指只有高低两档的厂商;GPT 列用于 codex。本项目实填四格均留占位。

| 档 | Claude | GPT | 两档厂商 | 本项目实填 |
|---|---|---|---|---|
| 顶级 | 主窗:fable 或 opus(fable 只当主窗,不派子代理) | 主窗:astra | 主窗:pro | {{顶级模型}} |
| 困难 | opus | astra | pro | {{困难模型}} |
| 日常 | sonnet | sol | flash(审计不过升 pro) | {{日常模型}} |
| 轻量 | haiku | luna | flash | {{轻量模型}} |

- 派给 GPT 系(本表 GPT 列的模型,以及 Codex 窗)的子代理或主窗工位时,派单 / 任务书首段原样带「做事标准：以堆砌防御代码、自加测试、过度封装为耻；以不影响功能的前提下用最少的代码、最直接的写法做完为荣。 能复用现有函数就不新写，能三行就不写十行，任务书没要求的一律不加。」;审计员再带「判据没要求的防御代码和测试，不因缺它判不符。」;其他模型不带。
- 同格几家 = 轮派,每窗自记上次派了谁,不设计数器、不设比例闸。
- {{拍板人}} 点到的格整格换,未点名的格沿上版并标注。
- 格外只三种:默认排队或限流 / 别家明显更顺手并写一句原因 / {{拍板人}} 点名;格外只报不拦。

来源注:「均分 = 轮派」是 MMO 总编排的转述扩写,不是其设计者原话,本仓采作做法句。

模型名会换代,换代只改本表不改任何规矩。
项目实填列由总监开窗第 0 步「识别模型」填进 `{{办公目录}}/模型对照表.md`(产品件只留占位)。
子代理档位与模型照 `{{办公目录}}/模型对照表.md` 实填列,{{拍板人}} 改口走当日口径一条,到期减法审回填本表。
本项目没有的平台整列留空。

## 四档用途

- 顶级:读订宪法与章程、推翻已判结论、多文件语义判断、与拍板人对接需求。主窗本体,不派子代理。
- 困难:跨文件状态机 / 协议编解码 / 持久化 / 账本与号源 / 解合并冲突 / 完整审计 / 起草任务书与需求件 / 甲类大型的执行员。子代理。
- 日常:普通改码、跑 build 与点名用例、轻审、格式转换与登记、单文件小修。子代理。
- 轻量:扫盘、读大件总结、抄数、校验和、按清单搬运、跑固定脚本;不审码、不审图。子代理。

派单、任务书、台面只写档位词,不写模型名。
