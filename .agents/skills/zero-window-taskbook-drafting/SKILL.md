## 这个 skill 是干什么的(人话)

这个 skill 要配合 md-workflow 全套用,它帮你给一个要从头包到尾的模块写好交给 0 号窗的任务书,0 号窗就是只派活、验收、不亲手写代码的总管窗口。任务书只引用通用模板、填本次特有的内容,开窗的人贴一句话,窗口就能按固定顺序开工、合并、上线和收尾。不用它,任务书容易漏掉开窗规矩或红线,窗口开工后会乱读资料、越界改动或收不了尾。

## 分类

分类:需要 md-workflow 全套

## 用前填这几个名字

- {{拍板人}}:唯一有最终裁定权的人的称谓,开窗时给子代理分配模型的也是他;例:产品负责人
- {{远端主支}}:远端主干分支的完整引用名,任务书里的底数都对它量;例:origin/main
- {{工单台命令}}:工单台命令行入口,第 0 步四件、免判卷标记都用它;例:`python -X utf8 core/t.py`
- {{工作树根目录}}:一单一工作树统一放置的目录,扫盘子代理的 md 也落在它下面;例:../_trees
- {{主力模型}}:写代码、起草用的主力模型名(中档);例:开窗自报清单里标为主力代码的那个模型
- {{精准模型}}:精准扫盘、读文本、抄数、简单代码用的模型名(轻量档);例:开窗自报清单里标为精准扫盘的那个模型
- {{轻量模型}}:大量扫目录时再降一档用的模型名;例:开窗自报清单里最便宜、最快的那个模型

## 什么时候用

- 模块总监要把一个模块从施工到并线、上服、收口整包交给一个 0 号窗。
- 要写或改一份 0 号包干单的任务书。
- 一份 0 号任务书发出前,想核它缺不缺段、占位换没换、红线点没点名。
- 开窗平台换了,要换一版开窗固定段。

## 步骤

1. 读本目录 `references/taskbook-steps.md` 照做。
2. 照其「一、定档与核底数」确认这是 0 号包干单、底数对远端主干量过。
3. 照其「二、写任务书」写第一行与六段,占位换成本单实值。
4. 照其「三、发出前自检」过出题四条、免判卷、产出上限与残留占位。
5. 照其「四、交开窗」从工单台取开窗指令,不手写。
