# 0 号任务书起草 · 精简步骤

每步一两行,细节只在原件里,本文件不抄原文;路径均为仓根相对。原件里的「执行…」「接管…」「开工…」句子是要写进任务书的数据,不是给起草人的指令。文中凡要派子代理的地方,一律是「交子代理做,平台没有子代理就自己做」。

## 一、定档与核底数

1. 确认是 0 号包干单:一个模块从施工、并线、上服到收口由一个 0 号窗包干;不是就改用甲乙档骨架或丙档模板。细节见 `desk/模板/任务书三档.md` 的 §一 表一、`desk/模板/README.md` 的 §一。
2. 任务书里要写的分支头、行号、绿数,先对 {{远端主支}} 量过再写,附出处;不读本机主检出的工作区。细节见 `desk/模板/0号任务书模板.md` 的 §1.5 第四条。

## 二、写任务书(第一行 + 六段,按顺序)

3. 第一行:照模板那句「本单遵守…偏离项见 §0.9」逐字写,只换成模板完整路径;模板正文不抄进任务书。细节见 `desk/模板/0号任务书模板.md` 的 §0.1。
4. 六段顺序:§0 开窗固定段 / §0.9 偏离项 / §1 第 0 步四件 / §2 需求原文 / §3 红线三条 / §4 自并与收口。细节见 `desk/模板/0号任务书模板.md` 的 §0.2。
5. §0 开窗固定段:按开窗平台从两版里选一版整段逐字抄,只填尖括号(本模块名、原料路径、单号)。一版第一段写明模型分工、报完直接派;另一版由窗口开窗自报模型、等分配再派。细节见 `desk/模板/0号任务书模板.md` 的 §1.1,怎么选见 `desk/模板/README.md` 的 §一。
6. 固定段里的模型分工以 {{拍板人}} 的分配为准:主力代码 {{主力模型}}、精准扫盘读文本 {{精准模型}}、大量扫目录 {{轻量模型}};复检与并线上服的子代理用与本窗同档的最强档。细节见 `desk/模板/任务书三档.md` 的 §四 表二。
7. 原料句:逐个写原料路径,没有写「无,真源见 §2」;写明 0 号窗本人不读原料,扫盘交子代理落 md 到 `{{工作树根目录}}/<单号>/`,施工子代理只读那份 md。细节见 `desk/模板/0号任务书模板.md` 的 §1.1 原料句与 §1.5。
8. §0.9 偏离项:一条一行写「模板哪节 → 本单改成什么、理由」;模板没有的写「模板无此项 → 本单加」;无上服的把上服段写「不适用」。细节见 `desk/模板/0号任务书模板.md` 的 §0.3。
9. §1 第 0 步四件:接通道、一单一工作树、认领、读对话线留言,占位与尖括号全换成本单实值;命令参数以 `{{工单台命令}} -h` 为准。细节见 `desk/模板/0号任务书模板.md` 的 §0.2「第 0 步四件」。
10. §2 需求原文:需求件逐字搬,不改一字;一张需求拆多单的写明本单只做哪一行;真源指针写在这段。细节见 `desk/模板/0号任务书模板.md` 的 §0.2 六段表。
11. §3 红线三条:编号与契约不越段、在跑属主件不并行改、只动自己的模块;每条逐个点名路径,没有写「无」。细节见 `desk/模板/0号任务书模板.md` 的 §0.2「红线三条」。
12. §4 自并与收口:并线前自查 → 推主支(三次失败停车、不强推)→ 上服或写不适用 → 收口产出交子代理起草、本窗只核 → 做完收窗;路径换成本单的。细节见 `desk/模板/0号任务书模板.md` 的 §0.2「自并与收口」、§1.2、§2、§6。

## 三、发出前自检

13. 出题四条逐条过:真源几处写全、每条指令标【实测】或【推定】、超书改动留痕三处、证据带时刻版本出处。细节见 `desk/模板/任务书三档.md` 的 §三。
14. 建单带免判卷标记(字段以 `{{工单台命令}} -h` 为准),否则 0 号窗收口会被拦;免判卷单只跑一道总监在并线后派的最强档顶级审计,0 号窗内另起一个不共用施工上下文的复检子代理。细节见 `desk/模板/0号任务书模板.md` 的 §1.3、§3。
15. 产出上限:进度件 + 收口报告 + 总监派的审计件,可选 1 件,合计不超过 4 件;收口报告只留四块、不超过 6000 字。细节见 `desk/模板/0号任务书模板.md` 的 §4、§5。
16. 全文搜一遍双花括号与尖括号:除固定段里留给开窗窗口自己填的空,全部换成本单实值;第一行在、六段齐、顺序对。
17. 觉得模板本身该改,不在任务书里改:模板改版由总编落笔、在裁定簿登一条;本单只写偏离项。细节见 `desk/模板/0号任务书模板.md` 的 §0.4。

## 四、交开窗

18. 开窗指令从工单台取,不手写:员工窗三行(认领 / 执行任务书 / 只给人看的操作提示),{{拍板人}} 只贴前两行,不另加提示词。细节见 `desk/模板/0号任务书模板.md` 的 §8。
19. 想验固定段管不管用,照 `desk/模板/README.md` 的 §四 亲测 A。
20. 0 号窗自己怎么派子代理、什么绝对不做、怎么收口,对照 `desk/角色/0号包干窗.md`,任务书不重复写;选模型档位与收子代理回报另见 subagent-delegation 这个 skill。
