# 工单台上服后，设计者只做这些

1. 在域名服务商把 `<你的域名>` 的 A 记录指向 `<服务器公网 IP>`。
   保存后等待解析生效。

2. 在云服务商的安全组新增入方向：`<服务端口>/TCP`(默认 8443)，来源只填自己的公网 IP 更安全。
   不改现有的其他规则。

3. 自己不登录服务器；由负责上服的窗口用既有免密方式执行安装(`install.sh`)。
   任何人都不要在聊天、文件或命令行参数里写密码。

4. 收到对话线“可以设密码了”后，30 分钟内用任意设备打开 `https://<你的域名>:<服务端口>/setup`。
   自己完成首次设密；超时只需让负责上服的窗口跑一次 `ticket.py account init --reopen-setup` 重开 30 分钟。

5. 登录后打开“我的令牌”，生成一次性可见的 API token，并把它单独保存到本机令牌文件。
   在 `remote.env` 只填写远程地址、令牌文件路径和证书指纹，不填写 token 本文。
