# 运行看板 · 本机运行观测

可选的本机会话观测工具，仅使用 Python 3 标准库，前端库已随目录提供，无需安装包或联网。

## 启动

在仓库根运行：

```bash
python -X utf8 core/tools/dashboard/server.py
```

隔离模式起法相同，加 `-I` 即可（如 `python -X utf8 -I core/tools/dashboard/server.py`）：不读环境变量、不从当前目录取模块，脚本按自身位置找到同目录代码，两种起法行为一致。

本机工单台服务已起时，顶栏「运行看板」在新标签打开站内 `/dashboard/`，与工单台同端口、同进程；接口统一位于 `/dashboard/api/`，不占用工单接口。远程监听、账号认证或 TLS 模式拒绝访问看板并显示原因。

也可独立运行上面命令，地址为 `http://127.0.0.1:8765/`；端口被占用时依次尝试到 8775，以终端输出为准。仅监听本机回环；可选 `--port` 指定端口、`--open` 打开浏览器，Windows 可双击 `启动看板.bat`。终端按 Ctrl+C 停止。

隔离运行时，可加 `--cache-dir 数据缓存/独立目录/`；路径相对本目录，必须是 `数据缓存/` 的严格子目录。缓存不入仓。独立样例入口为 `/?mock=1`，工单台样例入口为 `/dashboard/?mock=1`，均使用脱敏占位数据。

## 看什么

项目、窗口、子孙代理树、代理时间轴、在跑并发、按模型与按单汇总、规矩报警与历史统计。

**只覆盖 Claude Code 会话记录，codex / zcode 窗不在内。** 数据源仅只读 `~/.claude/projects`，不修改会话记录；按需提取用量、工具与窗口元数据，不展示对话正文。本机工单台首次访问看板时按需启动索引，缓存写入 `数据缓存/工单台_<数据目录摘要>/`，关闭服务时一并停止。

## 配置

修改本目录 `配置/价目.json` 调整模型单价，修改 `配置/计费口径.json` 调整按量、订阅与参考口径；默认值随产品提供。报警阈值在 `配置/报警阈值.json`。运行时会随扫描重载这些配置。

项目名、窗口别名与备注由页面保存到本地 `配置/备注.json`；文件未提供时使用空备注，首次保存时创建，不随产品分发。前端两件库与许可证见 `第三方库清单.md`，库文件保留原始包首声明。
