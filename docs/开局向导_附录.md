### 框架产物核验边界清单

第 9 步不等于项目全文件替换。所有产生或复制文件的步骤按下表归口;不在第 9 步核的不得据此宣称已核。

| 步骤 | 文件或产物 | 第 9 步核或不核及理由 |
|---|---|---|
| 0 | 系统临时框架副本全仓 | 不核,模板真源不填项目值 |
| 对接 1~5、4 | 需求原话、预设选择、三件、拆解清单、代码规范、可选素材管理 | 不核,已确认的用户产出及填好的规范,由对接确认与成立证据核;搬入不改变归属,不得批量替换用户文字 |
| 3、6、7a | 取值.json、生成件.json、开窗件原貌.json | 不作残留扫描,分别是替换映射、范围登记与旧字节证据,允许记录占位名;命令读取时核结构 |
| 4、12、13~17、24~25 | git 仓、索引、提交、远端配置与裸仓 | 不核,git 元数据,不是待填文档 |
| 5、7a | settings.json、hooks、codex 配置及备份 | 不核,各自配置步骤核合并、值与冲突;hooks 路径在第 11 步后填,备份保持原样 |

| 7、22 | 总编及所勾位章程;四格目录 | 章程登记核,填写槽在第 22~23 步核,激活目标在第 28 步核;空目录无文本 |
